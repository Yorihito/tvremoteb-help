接続とペアリング

テレビ側の準備（最初に 1 回だけ）

アプリからテレビを操作するには、テレビ側で次の 2 つを有効にしておく必要があります（BRAVIA の設定メニューから）。

  • IP コントロール — 設定 → ネットワークとインターネット → ホームネットワーク設定 → IP コントロール → 「認証」を 「正常な認証＋事前共有キー」または「正常な認証」 に。
  • リモート起動 — 同じくホームネットワーク設定内。これを有効にすると、テレビがスタンバイ中でもアプリから電源を入れられます。
iPhone とテレビは同じ Wi-Fi ネットワークに接続してください。ゲスト用 Wi-Fi など、機器どうしの通信が遮断されるネットワークでは使えません。

接続画面（テレビを選ぶ）

初回起動時、またはヘッダー左上の ボタンを押すと開きます。

  • 接続先のテレビ — 登録済みのテレビの一覧。タップで接続します。左にスワイプすると削除できます。
  • ネットワーク上で見つかったテレビ — 同じ Wi-Fi 上の BRAVIA（Google TV）を自動検出して表示します。タップすると登録＆接続します。
  • テレビを手動で追加 — 自動で見つからない場合に、IP アドレスを直接入力して追加します。名前は任意、MAC アドレスは電源オン（Wake-on-LAN）に使われますが、未入力でも接続後に自動取得されるので通常は空欄で大丈夫です。
テレビの IP アドレスは、テレビの設定 → ネットワークとインターネット → ネットワーク状態 で確認できます。

PIN ペアリング

初回のペアリングは、テレビの電源を入れた状態で行ってください。画面がオフ（スタンバイ）のままだとテレビが PIN を表示できず、ペアリングを開始できません。リモコンでテレビをオンにしてから接続してください。
  1. テレビを選んで接続すると、テレビ画面に 4 桁の PIN コードが表示されます。
  2. iPhone に表示された入力欄にその 4 桁を入力します。
    入力欄が「準備中…」と表示されている間は少しお待ちください。
  3. ペアリング をタップ。
    成功すると認証情報が iPhone に安全に保存され（Keychain）、次回からは PIN なしで自動接続します。

ペアリングに失敗した場合はエラーが表示されます。テレビ側の PIN 表示が消えてしまったときは、いったんキャンセルして接続し直すと新しい PIN が表示されます。

メディア画面（ジョグ／シャトル）

画面の構成

  • 再生情報カード（最上部) — 再生中の番組名やソースを表示。タップすると最新の状態に更新します。再生情報を返さないアプリでは「再生情報なし」になります。
  • モード切替 — ジョグ（コマ送り） と シャトル（可変速）。
  • ジョグダイヤル — 縁を指でなぞって回します。
  • ダイヤル中央の丸ボタン — 「決定（OK）」を送信。押すと沈み込んでクリック感があります。
  • 縦ホイール（右）・横ホイール（下） — 上下左右のカーソル移動。ダイヤルと合わせて十字キー代わりに。
  • 戻るボタン — 横ホイールの右。
  • 再生ボタン列（最下段） — 前へ／巻戻／再生／一時停止／早送／次へ。

ジョグモード（コマ送り）

ダイヤルを回した角度に応じて、少しずつ「送る／戻す」を繰り返します。時計回りで前へ、反時計回りで後ろへ。見逃したシーンをちょっとだけ戻したいときに便利です。

1 ステップに必要な回転角度は設定の「コマ送り感度」で調整できます。

シャトルモード（可変速）

ダイヤルをひねった角度で早送り／巻き戻しの速度段階が決まります。大きくひねるほど速く、中央の表示（≫ ×2 など）で現在の速度がわかります。指を離すとダイヤルがバネのように中央へ戻り、通常再生に戻ります。

1 段階に必要な角度は設定の「シャトル感度」で調整できます。

テレビには「なめらかなシーク」を直接指示する仕組みがないため、ジョグ／シャトルはリモコンボタンの連続送信で近似しています。動きの細かさ・反応はテレビの機種や再生アプリ・コンテンツ（録画番組か配信か等）によって変わります。録画番組の再生でいちばん効果を発揮します。

数字画面

チャンネルの直接選局と、メイン画面に載せていない補助ボタンの画面です。

  • 地デジ / BS/CS / 4K — チューナー切り替え（数字入力とセットで使うのでここにも配置）。
  • 1〜12 の数字キー — チャンネルのダイレクト選局。「10」は 0 キー、「11（枝番）」「12（選局）」付き。
  • ・ / 3桁 / 確定 — 3 桁チャンネル番号の入力用。
  • 補助ボタン — データ（d ボタン）／字幕／音声切替／表示／ヘルプ／停止／REC（録画）／レコーダー／クイック設定。

アプリ画面

テレビにインストールされているアプリの一覧を表示し、タップで起動します。起動すると自動でリモコン画面に切り替わるので、そのままカーソル操作を続けられます。

  • 一覧はテレビから自動取得します。下に引っぱると再読み込みできます。
  • よく使う動画アプリは、リモコン画面のストリーミングボタンに登録しておくほうが速く起動できます。

設定画面

言語

アプリの表示言語を「システム設定（iPhone に合わせる）」「日本語」「English」から選べます。変更はアプリを再起動すると反映されます（アプリを上にスワイプして終了 → 開き直し）。

接続中のテレビ

いま接続しているテレビの名前・IP アドレス・MAC アドレスを表示します。MAC アドレスはスタンバイからの電源オン（Wake-on-LAN）に使うもので、テレビから自動取得できた場合のみ表示されます。

リモコンのストリーミング

リモコン画面に表示する動画アプリのボタンを選びます。hulu / NETFLIX / U-NEXT / prime video / ABEMA / Disney+ / YouTube / My BRAVIA から最大 3 つ。タップでオン・オフを切り替えます（3 つ選択中は、どれかを外すと別のものを選べるようになります）。

音量プリセット

「YouTube を開いたら音量 15、テレビ放送に戻したら 30」のように、アプリや放送ごとにお好みの音量を覚えさせて、切り替え時に自動で合わせる機能です。TV の特性でアプリごとに基準の音量が違うことを補正できます。

使い方のおすすめ手順：

  1. 「音量プリセットを有効にする」をオン。
  2. テレビでふだんどおりの音量にしてから、各行の「…」メニュー → 「現在の音量を記憶」をタップ。
    いまテレビに設定されている音量がそのままプリセットになります。数値を直接 ＋／－ で調整しても OK。
  3. 「未設定」のままの項目は音量を変えません。
    「…」→「プリセットを解除」でいつでも未設定に戻せます。

細かい調整（通常は初期値のままで大丈夫です）：

項目意味
適用までの待ち時間アプリ起動から音量を変えはじめるまでの待ち秒数。アプリの起動が遅いテレビで、起動完了前に音量変更が空振りするときは長めにしてください。
連続送信の間隔コマンドを連続送信するときの 1 操作ごとの間隔。音量を 1 ずつ変えるときや、YouTube 速度マクロでカーソルを連続移動するときに使われます。届かない・飛びすぎる・取りこぼすときは少し長めにすると確実になります。
確認までの待ち時間変更後に「ちゃんと目標の音量になったか」を確認しにいくまでの待ち秒数。通常は変更不要です。

タブの並び順

画面下のタブ（リモコン・数字・メディア・アプリ・設定）の並び順を変えられます。セクション右上の「編集」を押してから、行をドラッグして並び替えてください。よく使う画面を端に寄せると親指が届きやすくなります。

ジョグ設定

項目意味
ハプティクスボタンやダイヤル操作時の振動（クリック感）のオン・オフ。
コマ送り感度ジョグモードで 1 ステップ送るのに必要な回転角度。小さくするほど敏感（少し回しただけで送る）、大きくするほどじっくり。
シャトル感度シャトルモードで速度が 1 段階上がるのに必要な角度。小さくすると少しのひねりで速くなります。

コマ送りの精度はテレビの機種や再生コンテンツによって変わります。お使いの環境で気持ちよく動くところを探してみてください。

センサー操作（実験的）

  • 伏せて自動ミュート — オンにすると、iPhone を画面が下になるように裏返して置くとテレビがミュートになり、持ち上げると元に戻ります。電話に出るときや席を立つときに、リモコンを探さずサッと消音できます。

アプリを開いている間だけ働きます。アプリ自身がかけたミュートだけを解除するので、手動でミュートした状態を勝手に戻すことはありません。置く／持ち上げる動作の取り違えを防ぐため、少し待ってから反応します。

切り替え・リセット・ペアリング解除

項目説明
別のテレビに切り替える接続画面を開きます。複数のテレビを登録して使い分けられます。
設定を初期値にリセット音量プリセット・ジョグ設定・ストリーミングの選択・タブの並び順を初期値に戻します。ペアリング（テレビとの接続）はそのまま残ります。言語と開発者モードも変わりません。確認ダイアログ付きなので、誤タップしても大丈夫です。
このテレビのペアリングを解除保存した認証情報とテレビの登録を削除し、設定も初期値に戻します。再接続するには PIN ペアリングをやり直します。テレビを買い替えたときや、接続をまっさらにやり直したいときに。

開発者モード

通常はオフのままで使ってください。オンにすると、お使いのテレビが対応しているリモコンコマンド（IRCC コード）の一覧が表示され、タップでそのまま送信してテストできます。「このボタン、うちのテレビで効くのかな？」を確かめたいとき向けの機能です。

困ったときは

症状確認すること
テレビが見つからないiPhone とテレビが同じ Wi-Fi か確認。iPhone の設定 → TV REMOTE for B → 「ローカルネットワーク」が許可されているか確認。見つからなければ IP アドレスで手動追加を。
「接続中…」のまま進まない／「画面がオフ」と出る初回ペアリング時はテレビの電源が入っている必要があります。リモコンでテレビをオンにしてから、もう一度「接続」してください。
接続エラーになるテレビ側の「IP コントロール」が有効か確認。テレビの再起動（コンセントの抜き差し）で直ることもあります。
スタンバイから電源が入らないテレビ側の「リモート起動」を有効に。Wi-Fi ルーターの設定によっては起動パケットが届かないことがあります。
一部のボタンが効かないリモコンコマンドはテレビの機種・ファームウェアにより異なります。スロー再生など一部の操作は機種によって非対応です。
「戻る」が 1 回で効かないYouTube などでは再生中の 1 回目の「戻る」は操作画面を消すだけです。もう 1 回押してください（テレビアプリ側の仕様です）。
再生情報が出ないアプリによっては再生情報を返しません。「再生情報なし」の表示は故障ではありません。
音量プリセットが効かないプリセットが「未設定」のままになっていないか確認。アプリ起動が遅い場合は「適用までの待ち時間」を長めに。
