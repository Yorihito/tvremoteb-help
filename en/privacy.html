Overview

TV REMOTE for B ("the app") respects your privacy. The app does not collect personally identifiable information (PII) or advertising identifiers. It does not track you across apps or websites, and it uses no third-party analytics SDKs.

Last updated: 2026-06-28

What we do not collect

  • Names, email addresses, phone numbers, or other personal data
  • Advertising identifiers (IDFA) or unique device identifiers
  • Location data
  • Your TV's IP address, MAC address, or host name (excluded/masked from any data sent)
  • Viewing history such as titles being played

Usage data (optional, off by default)

To help improve the app, the following anonymous data is sent only if you explicitly turn it on in Settings. It is off by default and can be turned off at any time. When off, nothing is recorded or sent.

  • TV model (e.g. XRJ-55X90L)
  • App version / build number
  • Device OS version (coarse)
  • Operation type (connect, pairing, power-on, …) with success/failure and response time (ms)

These are anonymous, one-off events not linked to you or your device. They are used to aggregate success rates and response times to tune IRCC codes and timing. All transmission is over HTTPS only.

Problem reports

From Settings → "Report a problem" you can send a bug report with diagnostics. Reports are posted as a public GitHub issue. You can review and edit the text before sending, and host names and IP/MAC addresses are excluded/masked.

Path: app → our proxy (which holds the submission token) → GitHub. Because the issue is public, remove anything you don't want shared before sending.

Data storage

Pairing credentials are stored in the device Keychain and are never sent elsewhere. The server that receives usage data does not store source IP addresses.
