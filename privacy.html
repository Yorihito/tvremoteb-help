はじめに

「TV REMOTE for B」（以下「本アプリ」）は、ユーザーのプライバシーを尊重します。 本アプリは 個人を特定する情報（PII）や広告識別子を収集しません。端末横断の トラッキングは行わず、サードパーティの解析 SDK も使用しません。

最終更新日: 2026-06-28

収集しない情報

  • 氏名・メールアドレス・電話番号などの個人情報
  • 広告識別子（IDFA）や端末を一意に識別する識別子
  • 位置情報
  • テレビの IP アドレス・MAC アドレス・ホスト名（送信データから除外・マスクします）
  • 再生中のタイトルなどの視聴履歴

使用状況データの送信（任意・既定オフ）

アプリの改善のため、設定で明示的にオンにした場合のみ、以下の匿名データを 送信します。既定ではオフで、いつでもオフに戻せます。オフにすると以後は記録も送信も 行いません。

  • テレビの型番（例: XRJ-55X90L）
  • アプリのバージョン／ビルド番号
  • 端末の OS バージョン（粗い粒度）
  • 操作の種別（接続・ペアリング・電源オンなど）と成否、応答時間（ミリ秒）

これらは匿名の単発イベントで、ユーザーや端末を識別する情報には 紐付きません。成功率や応答時間の集計に用い、IRCC コードや待ち時間の調整に役立てます。 送信は HTTPS のみで行われます。

問題の報告

設定の「問題を報告」から、診断情報を添えて不具合を報告できます。報告内容は 公開の GitHub Issue として投稿されます。送信前に本文を確認・編集でき、 ホスト名・IP/MAC アドレスなどは除外・マスクされます。

経路: アプリ → 当方のプロキシ（送信用トークンを保持）→ GitHub。 投稿は公開されるため、含めたくない情報は送信前に削除してください。

データの保存

ペアリングの認証情報は端末の Keychain に保存され、外部へ送信されません。 使用状況データを受け取るサーバーでは、送信元 IP アドレスを保存しません。
